# Mini-Courier Planner

## 1. Project Overview

Mini-Courier Planner is a Python-based courier
optimization system that selects parcels and
generates efficient delivery routes.

## 2. Objectives

- Prioritize parcels using sorting algorithms.
- Optimize parcel selection using 0/1 Knapsack.
- Calculate shortest paths using Dijkstra.
- Generate delivery routes using Nearest Neighbor TSP.
- Analyze algorithm execution time.

## 3. Problem Definition

The system manages multiple parcels with different
weights, priorities, and delivery deadlines.

The delivery vehicle has a fixed capacity of 20 kg.
The objective is to select valuable parcels and
generate an efficient delivery route.

## 4. Algorithms

1. Merge Sort - Parcel prioritization.
2. 0/1 Knapsack - Optimal parcel selection.
3. Dijkstra - Shortest path calculation.
4. Nearest Neighbor TSP - Route approximation.

## 5. Dataset

The initial dataset contains 5 parcels,
6 locations, and 11 roads.

## 6. Technology

- Python
- JSON
